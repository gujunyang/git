很多人问我，为什么去香港读研。

我说，是想亲眼看看——**一个城市的黄昏，和一个程序员的黄昏，哪个先来。**

后来我发现，先来的是凌晨四点的 bug。

***

我一直觉得，自我介绍是这个时代最廉价的东西。语言可以包装，人设可以精修，唯有 commit 不会说谎。所以我不打算在这里把自己夸成谁，我只想诚实地告诉你：

> **这个世界从不缺普通的人，缺的是能把普通活出分辨率的人。** 而我这块屏幕，分辨率还在调。

## 关于我

- 🎓 **在读研究生**——香港。一半在研究代码，一半在研究怎么把早八熬过去。
- 🧠 **INFP**——想很多、做很少。别人的人生是有规划的，我的规划是"先这样吧"。
- 🏀 **打篮球**——投不进，就是投不进，不像论文，写完自己也不知道写了什么。
- 🔌 **玩数码**——喜欢一切带电的、能联网的、能升级的东西。买回来、开机、升级，然后发现三年前的旧设备也能干一样的活。**像极了我从本科读到研究生**
- ☕ **作息**——Beta 版本。白天是条虫，晚上是条龙，生物钟按外星时区运转。

## 我在干什么

> `正在` 认真学习 · 认真摸鱼 · 认真研究下一台值得剁手的设备
> `计划中` 毕业 · 瘦十斤 · 把那个拖了半年的 side project 写完
> `已完成` 打开编辑器
